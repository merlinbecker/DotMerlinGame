## Bekannte Grenzen

- Eine Größe, die kein Vielfaches von 16 KiB ist, wird mit Füllbytes gebaut; das Ergebnis meldet es als `padded`.
- Code hinter einem `call` kann Daten sein. Das stört die Lesbarkeit, nicht die Byte-Treue.
- Bei sehr großen ROMs kann die Zeitgrenze des Builds greifen, dann lautet das Ergebnis „nicht geprüft“.
- Ab etwa 4 MiB ROM ist der Quelltext größer als die ZIP-Grenze beim Import.
- **Load ROM** bleibt bis zur Entscheidung des Projektinhabers bestehen (ADR-0005, Nachtrag M3).
