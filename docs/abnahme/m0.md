## Offen: manuelle Prüfung am Gerät

Durch den Projektinhaber in Chrome auf Android bzw. einem E-Ink-Gerät:

- [ ] Fußzeile zeigt denselben Commit wie `git rev-parse --short HEAD`
- [ ] Drehen wechselt sofort zwischen untereinander und nebeneinander
- [ ] Startzeit bis zur bedienbaren Shell unter 3 Sekunden (SC-002)
- [ ] Chrome DevTools → Application: Manifest ohne Fehler, kein Service Worker, App installierbar (offener Punkt PNG/SVG, research.md R6)
- [ ] Darstellung auf dem E-Ink-Gerät gut lesbar

## Hinweise

- `npm ci` meldet, dass das Installationsskript von `unrs-resolver` (über `eslint-plugin-import-x`) nicht ausgeführt wird. ESLint funktioniert ohne; das Skript bleibt bewusst nicht freigegeben.
- Die Pfeiltasten in den Kopfleisten sind `aria-disabled` statt `disabled`, damit sie per Tastatur erreichbar sind; der View-Wechsel kommt in M1.
