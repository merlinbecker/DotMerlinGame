# Adapter

Implementierungen der Ports aus `src/core/ports/` mit Fremdkomponenten (Emulator-Core, RGBDS-WASM, IndexedDB, ZIP). Fremdcode lebt nur hier bzw. in `third_party/`; jede Übernahme braucht einen Eintrag in `third_party/` und `THIRD_PARTY_LICENSES` im selben Commit. Erste Adapter entstehen in M1.
